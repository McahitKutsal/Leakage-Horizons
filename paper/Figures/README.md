# Which figures are live

**Live, and the only ones the manuscript references:** `figure-1` through `figure-7`, in `.svg`,
`.pdf` and `.png`. They are drawn by `scripts/build_figures.py` from the artefacts in `results/` and
are regenerated by

    python scripts/build_figures.py

Do not edit them by hand. An edit would survive exactly until the next run of that script, and the
whole point of generating them is that a series in a figure and a series in an artefact are one
object rather than two copies that can drift.

Each format has a job. The `.svg` is what `paper/penumbra-kbs.md` references and what
`scripts/build_paper.py` embeds in the `.docx`, where Word 2016 and later render the vector through
the `svgBlip` extension. The `.png` is the raster fallback the build injects beside each `svgBlip`,
because pandoc does not add one and an older reader would otherwise show nothing at all. The `.pdf`
is for the publisher: Elsevier wants vector artwork and prefers PDF or EPS.

**Superseded, kept for reference:** the `.drawio` sources and their `.drawio.svg` exports, named
`Figure N - description.drawio`. These were the hand-drawn figures, and the manuscript no longer
references any of them.

They are kept rather than deleted because one of them is evidence. `Figure 3 - a width printed in the
source.drawio` carried a fourteen-pixel vertical stagger on the five step functions of its panel A,
applied so the lines would not overplot; on an axis running 0 to 1 that stagger reads as presence
declining from 1.00 to 0.86 as the coded gap widens, which is a decline the data do not contain. An
external reader read it exactly that way, and D-46 records it. The `.drawio` source has since been
corrected, but its `.drawio.svg` export has **not** been regenerated and still shows the stagger, so
neither is safe to reuse.

That defect is also the reason this directory now works the way it does. A checker can compare a
number in the text against the artefact it came from; nothing we had could compare a *drawing*
against one. Generating the drawing from the artefact is the only version of that check we could
find (D-53).
