## Data and code availability

**Code.** The corpus construction, the diagnostic suite, the survival estimators, the synthetic generators and every analysis script are released as one repository at https://github.com/McahitKutsal/Leakage-Horizons, under the MIT licence. All reported figures are regenerated by named scripts from the stored results, and every stored result carries the command that produced it together with a three-integer fingerprint of the corpus version it was computed on. A consistency checker compares every registered number against the artefacts and is released with the rest, so that a reader can run the check rather than take its output on trust. The second, independent implementation of the density code is released alongside the first, together with the cross-check that compares them.

**The declaration.** The artefact Section 6.1's protocol rests on is deposited separately at https://doi.org/10.5281/zenodo.22110800, with a checksum for each file. It contains two documents whose evidential status differs. `pre-registration.md` is corpus A's declaration as the commit that froze it left it, and the repository's history carries the three commits that wrote and amended it, all before any data was materialised. `corpus-b-channel-declaration.md` assigns the ten interaction channels to target, contaminated and anchor, and is marked in the artefact itself as **not timestamped**.

**Data.** No third-party data is redistributed. Every source is public and none required an institutional affiliation of the authors. Six sources are used, each cited with the release the corpus was built from: the Correlates of War IGO membership register, version 3; the ATOP alliance register, version 5.1, member-level file; the DESTA trade agreement register; the Militarised Interstate Disputes register, MID5; the STRING interaction network, v12.0, *Homo sapiens*; and the CORUM and Complex Portal complex catalogues, both retrieved on 2 August 2026. Ideal-point estimates for United Nations voting come from the replication archive of the article cited for them. The derived corpus is reconstructible from those sources by the released scripts.

**Supplementary material.** The termination task, the full robustness grid behind Section 7.2, the complete bootstrap intervals for Table 7, and the per-corpus filter chains are in the supplementary material.
